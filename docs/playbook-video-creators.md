### 핵심 관찰 (수치로 확인된 것만)
- 같은 채널(김실장) 안에서 "장기렌트 vs 할부 vs 리스 vs 현금" 롱폼은 3만 회인데 그 쇼츠 컷은 2~3천 회. 롱폼을 잘라 만든 쇼츠는 약했음.
- 중고차파괴자는 "현금이냐 할부냐"처럼 한 번의 선택 질문 제목으로 100만 회, 이자 쇼츠는 24만 회로 쇼츠도 성공. 쇼츠는 설명란이 중고차 매장 광고라 사실상 영업 채널임(대가성 구조를 참고만 하고 우리는 따라 하지 않음).
- 배율이 가장 높은 것은 차알못 5번(2.1배): "월 유지비 + 보험료 + 세금"을 한 번에 묶은 항목 나열형.
- 장기렌트 장단점은 제목에 "업자 광고 아님"처럼 신뢰 선언을 넣은 영상이 20만 회(4번).

## 2. 영상별 구조 기록 (제목·메타 기반, 대본은 미확인)

| # | ① 첫 3초 훅 유형(추정) | ② 전개 순서(추정) | ⑥ 제목 공식 |
|---|---|---|---|
| 1 | 양자택일 질문 | 질문 -> 두 방식 비교 -> 조건별 결론 | `[상황]할 때 A로 살까? B로 살까?` |
| 2 | 월 납입액 고정 후 "무엇을 탈 수 있나" | 월 40만원 한도 -> 차종 후보 -> 비교 | `월 [금액]으로 [무엇]을 할 수 있을까?(기간)` |
| 3 | 질문 + 금액 궁금증 | 대출 조건 제시 -> 총이자 공개 | `[대상] 이자 얼마나 낼까?` (짧은 질문 1줄) |
| 4 | 신뢰 선언(광고 아님) | 장점 -> 단점 -> 계약·반납 체크사항 | `"광고 아닌" [주제] 장단점, 체크사항 [N]분이면 끝` |
| 5 | 항목 나열 약속 | 차량값 -> 월 보험 -> 세금 -> 합산 | `[차종] 월 유지비는? 보험료·세금까지 알아보자` |
| 6 | 반전 질문 + 실차주 | 구매가 -> 정비 내역 -> 총 지출 | `[차종] 정비비 폭탄? 실제 차주가 말함` |
| 7 | 금기 폭로 | 숨은 단점 나열 | `업계가 쉬쉬하는 진짜 단점` |
| 8 | 가격 반토막 + 소득 질문 | 시세 -> 연봉 기준 -> 유지비 합계 | `[감가 사실] [차종], 연봉 얼마면 탈 수 있나` |
| 9 | 시기·행동 유도 | 할인율 -> 신청 방법 | `내일부터 신청! 올해 변경되는 [세금] 할인` |
| 10-11 | 비교 약속 | 방식별 총비용 -> 결론 | `A vs B vs C, 진짜 이득 보는 방법` |
| 12 | 숫자 근거 | 이율 비교 | `[상품], 진짜 [대안]보다 괜찮은 이율인가요?` |
| 14 | 경고 | 위약금 사례 | `[단점] 하면 위약금 폭탄 맞습니다` |

CTA(⑤)는 영상 설명란에서 확인된 것만: 중고차파괴자는 전화·사이트 문의(매장 영업), 리스 계열 쇼츠는 업체 연락처·무료 계산기 파일 링크. 즉 "저장·댓글 키워드" 방식은 확인하지 못했고, 한국어 자동차 쇼츠의 주 CTA는 문의·상담 유도였음.

## 4. 공식의 흔한 실패와 우리가 피할 점

| 흔한 실패(채널들에서 보이는 패턴) | 문제 | 우리 규칙 |
|---|---|---|
| 제목의 "무조건 저렴", "사기", "폭탄" 단정 | 조건 빠진 일반화, 신뢰 하락 | 조건(금액·금리·기간)을 제목이나 첫 장에 같이 표기 |
| 설명란이 매장 광고·상담 번호 | 대가성/영업 영상이 정보 영상처럼 위장 | 광고·제휴 링크 있으면 첫 화면·캡션 앞부분에 고지. 심사 전엔 제휴 박스 끄기 |
| "내가 타봤다", "실제 차주" 연출 | 경험 날조 위험 | 직접 이용 경험을 쓰지 않음. "계산 결과", "공시 자료 기준"만 사용 |
| 오래된 영상(2019~2022) 숫자 그대로 인용 | 금리·세율 변경 | 모든 숫자에 기준일·가정 표기 |
| 장단점 영상에서 한쪽 상품 유도 | 편향 | 두 선택지 모두 손익분기 조건을 보여줌 |
| 롱폼을 그대로 자른 쇼츠(1번 관찰) | 약한 도달 | 쇼츠는 숫자 1개로 처음부터 다시 설계 |

## 5. 릴스 30초 구성안 2개 (모두 우리 계산값)

## 7. 제목 공식 10개 (우리 값으로)

8. 중고차 할부 계약 전 확인할 3가지: 연이율, 기간, 중도상환
9. 할부 기간 24개월 늘리면 이자가 얼마나 붙을까 (2,000만원 기준)
