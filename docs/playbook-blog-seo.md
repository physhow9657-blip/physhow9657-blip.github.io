# AutoCost Lab 블로그 SEO 플레이북

- 확인일: 2026-11-14
- 목적: 한국어 자동차 비용 검색 상위 글의 구조 패턴을 일반화해 우리 글 제목·구성에 적용한다. 문장·표·이미지는 옮기지 않았고, 아래 내용은 모두 패턴 요약이다.
- 방법: 공개 웹만 사용. 검색어 8개를 WebSearch로 보고 글 12개를 WebFetch로 열어 구조를 확인했다. 관찰 수치(글자수·헤딩 수)는 변환된 본문 기준 추정치다.
- 한계: 검색 순위·검색량·난이도는 도구로 측정하지 못했다(아래 "확인 못 한 점" 참조). 결과 노출은 미국 기준 검색이라 한국 실제 SERP와 다를 수 있다.

## 2. 상위 글 공통 승리 공식 Top 8

| 순위 | 공식 | 관찰 근거 | 우리 적용 |
|---|---|---|---|
| 1 | 제목 = 핵심 키워드 + 연도 + 변수/범위 + 결과물(계산법·비교표·체크리스트) | 1~8번 거의 전부 | 이미 대부분 충족. 다만 길이가 길고(65자 초과 다수) 질문형 훅이 부족 |

| 4 | FAQ 4~5문항(질문형 h3) | 2·3·6·7·8번 | `faq` 필드 있음. 문항 4개 이상, 본문에 없는 롱테일 질문으로 구성 |
| 5 | 비교표 1~2개(방식 비교·구간별 수치) | 1·2·3·5·8번 | 이미 많음. 모바일 가로 스크롤과 기준 문구 확인 |
| 6 | 수정일 + "20XX년 기준" 이중 표기 | 1·2·4·5·6·7·8번 | 우리는 `updatedDate`가 16개 중 2개뿐. 전 글 채울 것 |

| 8 | 관련 글·계산기로 이어지는 내부 링크 블록 | 3·8번 | "함께 보면 좋은 글"이 있음. 본문 중간에 계산기 링크 1개 추가 |

보조 관찰
- 업체 블로그(겟차 등)는 4~6천자로 길지만 출처가 없고 CTA가 3회 이상 반복된다. 길이로 이기려 하지 말고 출처·계산 근거로 이기는 편이 정책상 안전하다.
- 본문에 광고·제휴 표기가 없는 사례가 많다. 이를 따르지 말고 우리는 제휴 영역을 명시 표기한다.
- 질문형 소제목 비율은 글마다 0~50%로 편차가 크고, 질문형이 많다고 상위라는 상관은 보이지 않았다. h2는 평서형, FAQ h3만 질문형이 무난하다.

## 3. 애드센스 '가치 낮은 콘텐츠' 관점: 피할 것 / 해야 할 것

### 피할 것 (상위 글에서 관찰되었으나 우리가 따라가면 위험한 패턴)

| 패턴 | 관찰 위치 | 왜 위험한가 | 대안 |
|---|---|---|---|
| 같은 구조·문구를 연도·차종만 바꿔 대량 양산 | 업체 블로그 다수(제목 공식이 거의 동일) | 대량 생성·얇은 콘텐츠로 분류될 수 있음 | 글마다 고유 계산 예시와 실제 확인한 출처를 넣는다 |
| 출처 없는 수치(금리·위약금·km당 요금) | 3·4·5·7번 | 검증 불가, 신뢰 하락 | 공식 출처 URL + 확인일. 없으면 "가정"으로 명시 |
| 본문 전반에 CTA·견적 버튼 반복 | 4·5·6·7번 | 정보 글이 아니라 전환 랜딩처럼 보임 | 글당 제휴 박스 1개, 하단 배치, 광고 표기 |
| 도입부가 길고 결론이 끝에 있음 | 4·5·9번 | 이탈, 가치 낮은 느낌 | 첫 3문장에 결론 |
| 낡은 글(2020년)이 갱신 없이 상위 노출 | 9번 | 오래된 정보로 독자 피해 | 갱신일·기준일 표기, 분기 점검 |
| 날짜 불일치(수정일과 추천영역 날짜 다름) | 5·7번 | 신뢰 손상 | 날짜는 `pubDate`/`updatedDate` 한 곳에서만 |
| 타 사이트 문장·표 복붙, 이미지 무단 사용 | 일반 위험 | 저작권·중복 콘텐츠 | 공식 자료는 요지 요약 + 링크. 인용 15단어 미만 |
| 1,000자대 얇은 글, 이미지 11장 카드뉴스형 | 10번 | 텍스트 가치 부족 | 글당 CLAUDE.md 기준(1,500자 이상) 충족 + 표·계산 1개 이상 |
| 같은 계산기 CTA만 반복해 글을 계산기 입구로만 사용 | 3번 일부 | 글 자체 가치 부족 | 계산기는 보조, 글에서 판단 기준까지 완결 |
| 제휴·쿠팡 링크 도배 | 일반 위험 | 광고 과다, 제휴 목적 글 | 승인 전 `showAffiliates=false` 유지(메모리 지침) |

### 해야 할 것 (우리 강점을 정책 방어선으로)
- 모든 수치에 출처 URL + 확인일(정보 글 아래 "출처와 기준일" 섹션). 현재 일부 글만 있음.
- 가정 계산에는 "가정"이라고 명시하고 입력값을 공개.
- 작성자 이력(about 페이지의 경험)과 `updatedDate`를 일관되게 노출.
- 면책 문구는 필요한 글(세금·보험·금융)에만 짧게.

## 6. 글 작성 템플릿 (체크리스트)

1. 제목: 키워드 + 연도 + 숫자/변수 + 결과물, 55~65자. 질문형 훅은 2개 중 1개.
2. 첫 3문장: 결론 → 근거(공식 출처 이름) → 한계·조건.
3. 핵심 요약 `summary` 3~4개, 수치는 본문과 동일.
4. h2는 5~8개, 평서형 중심 + 질문형 1~2개. 표 1~2개, 계산 예시 1개(입력값 공개).
5. FAQ 4~5문항(본문에 없는 질문).
6. "출처와 기준일": 공식 URL + 확인일 + 변경될 수 있는 항목 표시.
7. `updatedDate` 반드시 입력, 본문에 "20XX년 기준" 1회.
8. 계산기 링크 본문 중간 1회 + "함께 보면 좋은 글" 3개.
9. 제휴·광고: 글당 1블록, 하단, "광고/제휴" 라벨. 승인 전 `showAffiliates=false`.
10. 분량: CLAUDE.md 기준 1,500~2,500자(공백 제외 체감)를 지킨다. 상위 글은 3천자 안팎이므로 여력이 있으면 3,000자까지는 허용하되 늘리기보다 출처·계산 근거를 채운다. 복붙·유사 문장 없음.

## 8. 확인 못 한 점

- 검색량·키워드 난이도·실제 한국 SERP 순위: 도구(검색광고·애널리틱스) 없이 정성 판단만 했다.
- WebSearch는 미국 기준이라 네이버 상위 글(블로그·카페)이 반영되지 않았다. 국내 상위가 네이버라면 구조가 다를 수 있다.
- 열지 못한 글: 위키독스 Insight_Lab 2건, 탑픽트리, eacar(인증서 오류). 글자수·헤딩 수는 변환 본문 기준 추정치.
- 공식 법령 원문은 검색 요약으로만 확인했고, 글 작성 시 조문을 직접 열어 재확인해야 한다.
- 우리 글 FAQ 문항 수와 본문 h2 길이는 개별 검증하지 않았다(`faq` 필드 존재만 확인).
- 애드센스 정책 문구 자체는 이번에 공식 정책 페이지를 열어 확인하지 않았다. "피할 것"은 일반 정책 취지 기반의 판단이다.
