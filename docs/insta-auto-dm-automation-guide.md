# 인스타 릴스 → 댓글 자동 DM → 블로그 전환 퍼널 구축 가이드

작성 기준일: **2026-11-14** · 대상: AutoCost Lab (Astro 블로그) + 인스타 프로페셔널 계정
요금·정책은 수시로 바뀝니다. 가입 전에 각 서비스 공식 페이지에서 최신 요금제를 확인하세요.

---

## 0. 전체 구조 (한 장)

```
[릴스 30초]
   └─ 캡션/영상: "댓글에 '계산기' 남기면 정리표 보내드려요"
        └─ [자동 DM] 키워드 감지 → 링크 1개 발송
             │   https://내도메인/posts/...?utm_source=instagram&utm_medium=reels&utm_campaign=reel01_tax
             └─ [블로그 글] 3초 요약 + 표 + 계산기
                  ├─ 애드센스 광고 (승인 후)
                  └─ 제휴 링크 (쿠팡/알리/장기렌트 CPA)
                       └─ [수익]
```

핵심은 **릴스로 유입, 블로그에서 전환**입니다. 인스타 인앱 브라우저는 체류시간이 짧고 애드센스
단가(RPM)가 낮기 때문에, 릴스 안에서 수익을 만들려 하지 말고 블로그로 넘기는 것이 정석입니다.

## 1. 자동 DM 도구 선택

| 도구 | 성격 | 요금(2026년 기준, 변동) | 잘 맞는 경우 | 주의 |
| --- | --- | --- | --- | --- |
| **소셜비즈** | 국내 다수 사용, 댓글 키워드→DM | 월 5천원대부터 | 댓글 자동 DM만 필요할 때 | 플랜별 발송 한도 확인 |
| **매니챗** | 무료 플랜 존재 | 무료 ~ 월 1만원대 | 처음 시작, 테스트 | 무료 플랜은 기능·발송 수 제한 |
| **인포크링크** | 프로필 링크 + 커머스 | 무료 ~ | 디지털 상품·공동구매 판매 | 자동 DM 기능은 별도 |
| **Meta 공식 API 기반 툴** | 안정성 최고 | 월 2만원 이상 | 계정을 오래 운영할 때 | 초기 설정 복잡 |

**선택 기준 3가지**

1. **인스타 공식 API를 쓰는가** — 비공식 자동화(스크래핑)는 계정 정지 위험이 큽니다.
2. **댓글 키워드 → DM 1회 발송**이 되는가 (대댓글 자동 답글은 끌 수 있어야 함).
3. **UTM 파라미터가 그대로 전달되는가** — 링크를 변형하면 어느 릴스가 전환을 만들었는지 못 봅니다.

## 2. 세팅 순서 (30분)

1. **인스타 프로페셔널 계정 전환** — 설정 → 계정 유형 → 프로페셔널(크리에이터). 무료.
2. **자동 DM 도구 연결** — 인스타 계정 권한 승인. 이때 '메시지 관리' 권한을 반드시 포함.
3. **키워드 트리거 등록** — 글마다 `instaKeyword`(예: `계산기`, `유지비`, `보험`)를 하나씩 등록.
   - 대소문자·띄어쓰기 변형도 함께 등록: `계산기`, `계산`, `calc`.
   - 부분 일치가 아니라 **정확 일치**로 설정해 오탐을 줄입니다.
4. **첫 DM 문구 작성** (아래 §3 템플릿). 링크는 **1개만**.
5. **테스트** — 본인 계정이 아닌 지인 계정으로 댓글을 달아 DM 수신 확인. 링크 클릭 → UTM 유지 확인.

## 4. 계정 제재를 피하는 규칙 (가장 중요)

인스타는 자동화를 **공식 API 범위 안에서만** 허용합니다. 아래를 지키면 대부분 문제가 없습니다.

| 규칙 | 이유 |
| --- | --- |
| **공개 댓글에 자동 대댓글 금지** (DM만 발송) | 공개 답글이 반복되면 스팸으로 신고·차단됩니다 |
| 같은 문구 반복 금지 → 3~4개 변형을 순환 | 동일 메시지 대량 발송은 스팸 판정 1순위 |
| 1일 DM 150건 이하, 분당 10건 이하로 제한 | 신규 계정일수록 보수적으로(첫 달 50건/일) |
| 팔로우하지 않은 계정에 먼저 DM 금지 | 인스타 정책 위반 |
| 계정 나이 2주 이상 + 팔로워 100명 이상 된 뒤 자동화 시작 | 신규 계정은 자동화 탐지에 취약 |
| 비공식 크롬 확장·스크래핑 툴 사용 금지 | 계정 영구 정지 사례 다수 |
| 키워드에 오탐 유발 단어(예: `차`) 단독 등록 금지 | 무관한 댓글에 DM이 나가 신고 위험 |
| 링크는 도메인 하나만 | 다중 도메인 링크는 피싱 패턴으로 분류될 수 있음 |

**안전 운영 순서**: 1주 차는 자동화 없이 수동 DM으로 문구·전환율을 확인 → 2주 차부터 자동화 켜기.

## 5. 애드센스 무효 트래픽 방지 규칙

자동 DM으로 유입을 만들면 **본인·지인 클릭**이 섞이기 쉽습니다. 애드센스는 이를 무효 트래픽으로
판정하고 수익을 회수하거나 계정을 정지시킵니다.

- **절대 금지**: 자기 글의 광고 클릭, 가족·직원에게 클릭 요청, "광고 눌러주세요" 문구, 클릭 유도
  이미지(광고 위에 화살표 등), 자동 새로고침·팝업으로 광고 노출 늘리기.
- **해도 되는 것**: 글 링크 공유, 저장 유도, DM으로 글 링크 발송.
- **권장**: DM 링크와 본인 테스트 링크에 `utm_content=test` 를 붙여 구분. 애드센스 보고서에서
  예상 밖의 클릭률(CTR 10% 초과)이 보이면 즉시 유입 경로를 점검.
- 릴스에서 "링크 타고 들어가서 광고 눌러주세요" 같은 문구는 **절대 금지**입니다. 계정 정지 사유입니다.

## 6. 제휴 연결 구조 (수익 3층)

| 층 | 상품 | 연결 위치 | 정산 | 특징 |
| --- | --- | --- | --- | --- |
| 1층 (즉시) | 쿠팡파트너스 (차량·바이크 용품) | 블로그 `AffiliateBox`, 릴스 캡션 | 월 정산(익월) | 전환 빠름, 단가 낮음(3% 내외) |
| 2층 (즉시) | 알리 어필리에이트 (부품·소모품) | 블로그 비교표 하단 | 월 정산 | 단가 낮지만 저가 구매 전환 높음 |
| 3층 (고단가) | 장기렌트·리스 CPA (스와퍼 등) | 장기렌트 비교 글, DM | 리드/계약 단위 | 1건 수수료가 가장 큼, 상담 폼 연결 필수 |
| 별도 | 디지털 상품(유지비 시트·체크리스트) | 인포크링크 | 즉시 | 수수료 0%, 반복 판매 가능 |

**연결 순서**: 쿠팡 승인(1~3일) → 링크 발급 → `src/config.ts` `affiliates.coupang.url` 입력 →
`showAffiliates: true` → 릴스 1편 발행 → DM 자동화 → 2주 후 성과 보고 종류 확장.

## 7. 측정 지표 (주 1회 5분)

| 단계 | 지표 | 목표(초기) | 보는 곳 |
| --- | --- | --- | --- |
| 릴스 | 조회 → 댓글 비율 | 0.5% 이상 | 인스타 인사이트 |
| 댓글 → DM 발송 | 발송 성공률 | 95% 이상 | 자동 DM 툴 |
| DM → 링크 클릭 | 클릭률 | 25% 이상 | UTM + 애널리틱스 |
| 링크 → 체류 | 평균 체류 60초 이상 | 60초 | 애널리틱스 |
| 전환 | 제휴 클릭률 | 3% 이상 | 제휴 대시보드 |

CTR이 비정상적으로 높거나(10% 초과) 체류가 5초 미만이면 유입 품질을 먼저 의심하세요.

## 8. 릴스 제작 체크리스트

- [ ] 3초 안에 결론(숫자)을 말한다 — "등록비 140만원입니다"
- [ ] 30초 이내, 자막 필수(무음 시청 80%)
- [ ] 화면에 표 1개 이상 노출(신뢰도)
- [ ] 마지막 3초에 키워드 안내 + 고정 댓글에 동일 안내
- [ ] 캡션 첫 줄에 대가성 문구(제휴가 있으면)
- [ ] 프로필 링크는 최신 글로 교체
