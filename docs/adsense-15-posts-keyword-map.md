# 애드센스 승인 15편 키워드 맵 + 1일 차 수익화 5선

작성 기준일: **2026-11-14** · 대상 사이트: `AutoCost Lab` (Astro 정적 블로그)
CPC 등급은 국내 자동차·보험·금융 키워드의 통상 범위를 기준으로 한 **상대 등급**(상 / 중상 / 중)입니다.
실제 클릭당 단가는 광고주 입찰·계절·방문자 국가에 따라 매일 바뀌므로 금액을 확정하지 않습니다.

---

## 0. 먼저 읽을 것 — 승인 순서와 수익화 스위치

이 프로젝트는 **"승인 먼저, 제휴는 그다음"** 구조로 설계되어 있습니다.
`src/config.ts` 의 스위치 두 개로 시점을 통제합니다.

| 시점 | `adsense.enabled` | `showAffiliates` | 하는 일 |
| --- | --- | --- | --- |
| 1일 차 (승인 전) | `false` | `true` (제휴 링크를 실제로 넣은 경우) | 인스타 릴스 → 자동 DM → 블로그/제휴 링크로 **바로 수익** |
| 승인 신청 직전~심사 중 | `false` | **`false` 권장** | 정보성 글 15편만 있는 깨끗한 사이트로 심사 |
| 승인 직후 | `true` | `true` | 애드센스 + 제휴 동시 운영 |

> **왜 심사 중에는 제휴를 끄나요?**
> 제휴 링크만 잔뜩 있는 글은 애드센스가 말하는 *가치 없는 콘텐츠(Thin content)* 또는
> *제휴 도배(affiliation-focused)* 사이트로 판단되기 쉽습니다. 정보성 글이 15편 이상 쌓인 뒤
> 승인을 받고, 그 다음에 제휴 CTA를 켜는 것이 가장 빠르고 안전합니다.
> 처음부터 제휴로 수익을 내고 싶다면 릴스→DM 구간에서 수익을 만들고, 블로그는 심사용으로 비워 두세요.

**승인 체크리스트**

- [ ] 정보성 글 15편 이상 (각 1,200자 이상, 표·이미지·직접 계산 최소 1개)
- [ ] 소개(운영자 실명·경력·연락처) / 개인정보처리방침 / 문의 페이지 존재
- [ ] `robots.txt` 에 `Mediapartners-Google` 허용, `ads.txt` 게시자 ID 교체
- [ ] 사이트맵 제출 (Google Search Console) + RSS 동작
- [ ] 다른 사이트 글 복사 없음, AI 초안 그대로 붙여넣기 없음(수치·경험 반드시 추가)
- [ ] 깨진 링크 0개 (배포 후 `npm run build` + 링크 점검)

## 2. 1일 차 즉시 수익화 — 제휴·CPA 릴스 + 블로그 글감 5선

애드센스 승인(2~4주)을 기다리지 않고 **사이트 오픈 첫날부터** 수익이 나는 구조입니다.
수익 경로: **릴스 → 댓글 키워드 → 자동 DM(짧은 링크) → 블로그 비교글 또는 제휴 링크 직접 클릭 → 구매/견적**.

| # | 글감(블로그) / 릴스 | 릴스 3초 훅 | DM 키워드 | 1차 수익 경로 | 2차 수익 경로 | 전환 포인트 |
| --- | --- | --- | --- | --- | --- | --- |
| M1 | 차량용 방한·세차용품 실사용 비교 (와이퍼·부동액·김서림 방지) | "겨울에 앞유리 안 닦이는 이유, 용품 3개로 해결" | `겨울용품` | 쿠팡파트너스 링크 | 애드센스(승인 후) | 1~3만원 저가라 구매 결정이 빠름. 3개 비교표로 신뢰 확보 |

### 5선 운영 규칙

1. **글은 정보, 링크는 도구.** 제휴 링크만 있는 300자 글은 애드센스 승인도, 구글 검색도 통과하지 못합니다. 제품 3개 이상 비교 + 실제 사용 조건 + 단점 1개를 반드시 넣으세요.
2. **DM은 링크 1개만.** 링크를 2개 이상 보내면 클릭률이 절반으로 떨어지고 스팸 신고 위험이 커집니다.
3. **대가성 문구는 캡션 첫 줄 + 블로그 상단.** `#광고` `#제휴` 해시태그도 함께 표기합니다(아래 §3).
4. **CPA는 상담 폼까지 걸리는 시간이 짧은 것부터.** 장기렌트는 '월 납입금 조회'만으로 리드가 발생합니다.
5. **릴스 1개 → 글 1개 → DM 문구 1개**를 세트로 만드세요. 릴스만 만들고 랜딩이 없으면 수익이 0입니다.

## 3. 대가성 표기 규칙 (공정거래위원회 심사지침)

- **블로그**: 제휴 링크가 처음 나오는 위치보다 위에 표시. 이 프로젝트는 `src/config.ts` 의
  `affiliates.disclosure` 문구가 `AffiliateBox` 상단 카드와 본문 하단에 자동 표시됩니다.
- **인스타 캡션**: 첫 2줄 안에 표시(더보기 클릭 전에 보이도록).
  - 예: `이 게시물은 쿠팡 파트너스 활동의 일환으로 수수료를 받습니다. #광고 #제휴`
- **릴스 영상 자체**: 화면 하단에 3초 이상 `광고·제휴 포함` 자막을 넣는 것을 권장합니다.
- 금지: "내돈내산"이라 쓰고 실제로 제공받은 제품을 소개하는 것, 수수료 사실을 숨기는 것,
  특정 제품을 실제보다 좋게 평가하는 것.

## 4. 스위치 전환 순서 (복붙용)

```ts
// src/config.ts
showAffiliates: true,    // 1일 차: 켜고 제휴 링크 채우기
adsense: { enabled: false, ... }

// 승인 신청 3일 전
showAffiliates: false,   // 심사용 깨끗한 사이트

// 승인 메일 받은 직후
adsense: { enabled: true, client: 'ca-pub-실제ID', slots: { ... } }
showAffiliates: true,
```

전환 후에는 `npm run build` → `git push` 만 하면 1~2분 뒤 배포됩니다.

## 5. 키워드 선정 기준 (다음 글을 고를 때)

1. **검색 의도가 '돈'에 가까운가** — "취등록세 계산" > "자동차 역사".
2. **내가 실제로 겪은 일인가** — 경험 없는 주제는 3개월 안에 순위가 빠집니다.
3. **표로 정리할 수 있는가** — 표가 들어가면 체류시간이 1.5배 이상 늘어납니다.
4. **계절성** — 11~2월은 방한·배터리·부동액, 3~5월은 타이어·세차·나들이.
5. **경쟁도** — 상위 5개가 대형 커뮤니티·정부 사이트뿐이면 피하고, 개인 블로그가 섞여 있으면 도전.
